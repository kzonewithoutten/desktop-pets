# Desktop Pets

Персонажи, которые живут у тебя на рабочем столе: гуляют по панели задач, спят, едят, болтают друг с другом в манга-облачках, прыгают по иконкам, гоняются друг за другом и прячутся. Персонажей, их рисунки, реплики, отношения и сценки делаешь сам в редакторе, без кода.

*Desktop pets for Windows with a visual editor: make your own characters, frame-by-frame animations, lines, relationships and scenes. The interface is in Russian.*

## Скачать

**[Последняя версия → Releases](../../releases/latest)** — скачай zip, распакуй, запусти `Desktop Pets.exe`. Python ставить не нужно.

Начинается пусто: нажми **«+ Персонаж»** в `Desktop Pets — редактор.exe`.

## Что умеет

- **Свои персонажи.** Без рисунков персонаж рисуется кругляшом твоего цвета, а ты постепенно вставляешь свои покадровые PNG (холст ~200×200, лицом вправо, ноги на нижнем краю, прозрачный фон). У одной анимации может быть несколько вариантов, они играются по очереди или случайно.
- **Сам живёт.** Гуляет, спит, когда устал, ест, когда голоден, занимается спортом, смеётся, пытается сбежать (гонится за курсором, колотит в экран, лезет вверх), работает, читает. Ты задаёшь, как часто он делает каждое.
- **Отношения.** «Охотится на»: обходит экран со сканером, находит, гоняется, дерётся. «Защищает»: прячет за спиной, заступается, разнимает драку. А ещё «пристаёт к» и «болтает с».
- **События (сценки).** Кто участвует, когда (иногда / рядом / далеко / по клику / при перетаскивании / при запуске…) и шаги: кто что говорит и какую анимацию играет. Есть версии «рядом» и «далеко»: издалека кричат через экран, вблизи разговаривают.
- **Свои анимации на события:** по клику, рядом или далеко от кого-то, в ответ на чужую анимацию, сидя на иконке рабочего стола. Область экрана, где они могут играть, обводится на карте.
- **Мышкой.** Можно перетаскивать, кидать, закидывать на иконки, тыкать. Если перетащить одного к другому, начнётся событие.
- **Манга-облачки:** обычная речь, взрыв для крика, пунктир для шёпота, роботская плашка. Свой шрифт кидается в `fonts/`.
- Персонажи видны **только на рабочем столе** и прячутся, когда открыта программа (это отключается). Есть автозапуск с Windows.
- **Пакет для друзей.** Редактор сам собирает zip с готовыми .exe и выбранными персонажами.

## Запуск из исходников

Нужен Windows и Python 3.10+ (с tkinter, он идёт в стандартной установке). Других зависимостей нет.

```bash
python main.py
```

```bash
python editor.py
```

Или запускай `Desktop Pets.bat` и `Редактор.bat`.

Собрать .exe-пакет: кнопка **«📦 Собрать пакет для друга…»** в редакторе или

```bash
python build.py --name "Desktop Pets" --chars ""
```

При первой сборке поставится PyInstaller.

## Где что лежит

```
data/characters/<персонаж>/   настройки (character.json) и папки с кадрами анимаций
data/events.json              события
data/settings.json            общие настройки
fonts/                        шрифты облачков
```

Удалённое в редакторе уходит в `data/_корзина`.

## Шрифты

В комплекте [Balsamiq Sans](https://github.com/balsamiq/balsamiqsans), [Rubik Mono One](https://github.com/googlefonts/rubik), Pangolin, Rampart One и Reggae One из [Google Fonts](https://github.com/google/fonts) под лицензией SIL Open Font License (тексты в `fonts/лицензии`).
